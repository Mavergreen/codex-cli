First release. OpenAI's Codex CLI 0.161.0 (`codex`), built for Mac OS X 10.9 Mavericks on Intel Macs. This is an unofficial, community build, not affiliated with or endorsed by OpenAI. It is built from Codex's sources as modified by this repo's patches; Wowfunhappy wrote patches 0001 to 0007, and Wowfunhappy's native 10.9 build of Codex came first.

What you get:

- **Where it goes.** `codex` and `codex-code-mode-host` are installed side by side in `/usr/local/mavergreen/codex-cli/bin`. Only `codex` is linked into `/usr/local/mavergreen/bin`, which is on the login `PATH`. Codex's `LICENSE` and `NOTICE`, the README and the build manifest are in `/usr/local/mavergreen/codex-cli/share/doc/codex-cli`.
- **Root certificates.** Sign-in and API access check servers against the roots in the keychain's trust settings. A stock 10.9 lacks ISRG Root X1 there, so install AquaTransport's ModernRootCertificates package first; that is the setup this release was tested with.
- **No voice.** The voice runtime is not built or shipped, so Codex's voice features are unsupported.
- **Three defaults differ from upstream's.** The startup update check (patch 0002) and the shared background daemon (patch 0003) are off; turn them back on in `~/.codex/config.toml` with `check_for_update_on_startup = true` and, under `[features]`, `daemon_auto_start = true`. Biometric user verification (patch 0004) always reports unsupported, because 10.9 lacks LocalAuthentication and the Secure Enclave.
- **Harmless warnings.** `codex exec` prints a few `FSEventsPurgeEventsForDeviceUpToEventId ... failed: 5` lines per run. Codex's file watcher (notify 8.2.0) calls a function only root may call; the lines go away when Codex moves to notify 9.
- **Updates and uninstalling.** The included updater checks for new releases once a day and posts a notification when one is available. `sudo mavergreen uninstall codex-cli` removes the package and leaves your `~/.codex` alone.

Checked before release on Mac OS X 10.9.5: the native package and a package of the cross-built binaries each installed and passed `codex --version`, `--help`, `codex sandbox -- /usr/bin/true`, an `exec` turn that ran commands through the Code Mode host, and an interactive TUI turn; the native one also signed in with `codex login --device-auth` on a clean profile. Details are in `docs/compatibility-matrix.md`, each patch is explained in `patches/README.md`, and `PROVENANCE.md` records where Wowfunhappy's patches came from.
