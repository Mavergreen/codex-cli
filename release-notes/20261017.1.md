First release. OpenAI's Codex CLI (`codex`) for Mac OS X 10.9 Mavericks on Intel Macs, which installs and updates itself from builds made for 10.9. This is an unofficial, community build, not affiliated with or endorsed by OpenAI. Codex is built from its sources as modified by this repo's patches; Wowfunhappy wrote patches 0004 to 0007, and Wowfunhappy's native 10.9 build of Codex came first.

What you get:

- **How it installs.** This package installs a small `codex` launcher in `/usr/local/mavergreen/bin`, which is on the login `PATH`. It needs the `rg` and `ed25519` packages, and AquaTransport (see below). The first time you run `codex`, it downloads the newest Codex build for 10.9 into your `~/.codex/packages/standalone`, checks its signature and checksum, and runs it; this takes a minute. Each user on the Mac gets their own. It also points `~/.local/bin/codex` at the launcher, unless something else is already there.
- **Updates.** Codex tells you when a newer build is available, as upstream's does, and `codex update` installs it, with no admin password. A new build follows each Codex release once it has been built for 10.9, and also comes when this project changes how Codex is built. `codex --version` prints OpenAI's version (`0.161.0`); `codex doctor` shows the build on its `running build:` line, such as `0.161.0-mavericks.1`.
- **Stepping back.** To go back to an older build, run `/usr/local/mavergreen/codex-cli/libexec/codex-cli/install.sh --release 0.161.0-mavericks.1` (any build still on the channel). Codex will offer the newest build again; to stay where you are, put `check_for_update_on_startup = false` in `~/.codex/config.toml`.
- **When a build needs a newer package.** Now and then a build needs a newer version of this package. Then the update installs nothing and says so, and the package's own updater offers the new package; you can also get it from https://github.com/Mavergreen/codex-cli/releases/latest.
- **The package's updater.** The included Sparkle updater checks once a day for new releases of this package. It changes only when the launcher, the installer or the updater do; ordinary Codex updates never go through it.
- **AquaTransport.** Codex's HTTPS on 10.9 goes through Wowfunhappy's AquaTransport, and needs a release that has the TLS fixes Codex's native-tls depends on. That release is not out yet, so its minimum version is pending. Get AquaTransport from https://mavericksforever.com/downloads/AquaTransport.dmg. The `codex` launcher refuses to run, and says why, when AquaTransport is missing or older than this package needs. AquaTransport speaks TLS 1.0 to 1.3, so Codex needs no fallback from native TLS to rustls here. Codex's WebSockets and its OTLP gRPC export still use rustls with the Mac's keychain roots, so on those AquaTransport's ModernRootCertificates may still matter.
- **Not supported.** Voice; `codex app`, which downloads OpenAI's desktop app, which does not run on 10.9; and the `shell_zsh_fork` feature, which needs OpenAI's prebuilt zsh. Biometric user verification always reports unsupported, because 10.9 lacks LocalAuthentication and the Secure Enclave.
- **Harmless warnings.** `codex exec` prints a few `FSEventsPurgeEventsForDeviceUpToEventId ... failed: 5` lines per run. Codex's file watcher (notify 8.2.0) calls a function only root may call; the lines go away when Codex moves to notify 9.
- **Uninstalling.** `sudo mavergreen uninstall codex-cli` removes the launcher, the installer and the updater, and leaves your `~/.codex`, including the Codex it installed there, alone.

Testing this release's self-updating layout on Mac OS X 10.9.5 is still to be done; it waits for the AquaTransport release Codex needs. The checks it will run are listed in `docs/compatibility-matrix.md`. Each patch is explained in `patches/README.md`, and `PROVENANCE.md` records where Wowfunhappy's patches came from and where the installer came from.
